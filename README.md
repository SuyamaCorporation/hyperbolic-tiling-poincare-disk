# Hyperbolic Tiling Poincaré Disk Generator

Renders {p,q} hyperbolic tilings in the Poincaré disk model using Möbius transformations and geodesic arc rendering; supports {4,5}, {3,7}, {5,4}, and {6,4} tilings with depth, rotation, and color mode controls. Features BFS tile expansion up to 2000 tiles, animated rotation, and PNG export.
